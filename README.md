# ChannelFinder

Telegram bot allowing an owner to register a single channel and returning a temporary reply with a button linking to the channel when users search its name; replies auto-delete after 5 minutes.

Spec: [`docs/blueprint.md`](docs/blueprint.md).

Built on [agnt-gm.ai](https://agnt-gm.ai). The whole bot is built and refined here as pull requests across successive build passes.
